# 网络安全学习笔记 📚🔐

本项目是个人在网络安全学习过程中整理的学习笔记，涵盖了从入门到进阶的多个方向和技能模块。

## 🧠 学习路径概览

本笔记内容按模块整理，包含以下主要学习方向：

### 1. 信息收集
- Web 信息收集方法与工具
- 子域名收集、端口扫描、指纹识别等

### 2. 基础入门
- 网络协议、HTTP 报文、编码解码、加密基础等
- 常用命令、基础脚本、漏洞原理介绍

### 3. 编程开发
- Python、Golang、C、JavaScript等安全开发
- 自动化脚本与漏洞利用编程

### 4. WEB安全
- SQL注入、XSS、SSRF、命令/代码注入
- 文件上传绕过、Webshell利用等

### 5. 渗透测试
- 渗透测试流程与实战技巧
- 权限维持、提权方法、痕迹清除等

### 6. Web3安全
- Solidity 安全开发、常见攻击方式
- 区块链审计思路

### 7. API安全
- API攻击面识别、身份认证绕过
- 常见API漏洞利用案例

### 8. APP安全
- Android/iOS 应用逆向与Hook技术
- 抓包、反编译、动态调试等技巧

### 9. 云上攻防
- 云服务基础（阿里云、AWS、腾讯云）
- 云服务权限绕过与滥用攻击

### 10. 安全开发
- 安全编码规范、开发流程中的安全
- DevSecOps 安全实践

### 11. 红队测试
- 内网渗透、域渗透技巧
- 横向移动、持久化、痕迹清除等

### 12. 二进制漏洞
- 栈溢出、格式化字符串漏洞分析
- PWN与逆向工程基础

### 13. 高级攻防
- 架构安全、APT攻击链分析
- 攻防演练、攻防对抗推演

### 14. 安全运营
- 风险评估、日志分析、漏洞响应
- 态势感知平台使用

### 15. 威胁情报
- 数据来源、威胁情报分析流程
- IOC提取与追踪溯源

### 16. 代码审计
- 常见漏洞审计方法
- PHP、Java、Python等代码审计案例

### 17. 安全工具开发
- Burpsuite 插件编写、Python工具开发
- 自动化测试工具实战

### 18. 安全设备
- WAF、IDS/IPS、防火墙设备使用与绕过技巧

### 19. 取证分析
- 数据恢复、日志溯源、流量分析
- Windows、Linux 取证思路与工具使用

### 20. CTF学习
- CTF题型讲解、靶机实战记录
- 各类 Writeup 与战队训练笔记
